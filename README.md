# Strength Analytics

A personal Python project designed to measure and analyze strength across workouts and exercises, with the long-term goal of providing insights into training performance and visualizing user-provided data.

## Current Features
- Estimated one-rep max calculation using the Epley formula
- Weight rounding
- Barbell plate calculator assuming standard commercial gym equipment and unlimited plate availability

## Planned Features
- Support for pounds and kilograms
- Customizable plate inventories and barbell weights
- Additional strength estimation methods
- Workout tracking and performance analysis
- Data visualization and a graphical user interface

## Project Status
Early development, currently focused on implementing the core calculations.
